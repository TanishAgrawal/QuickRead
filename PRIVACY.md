# QuickRead Privacy Policy

Effective date: November 10, 2026

QuickRead is a Chrome extension maintained by [TanishAgrawal](https://github.com/TanishAgrawal).
It displays text you select on a webpage in a floating reader. This policy covers
the QuickRead extension.

## Text you choose to read

When you activate QuickRead, it accesses the text you selected on the current
webpage and processes it locally to display words, reading progress, and adjacent
context. This can include text selected in ordinary input fields and textareas;
password fields are excluded.

Selected text is held in memory for the reading session. QuickRead does not save
it to persistent storage or send it to the developer, a server, or a third party.
Resetting or replacing a session discards the previous text; closing the reader
or unloading the page ends that session.

## Saved preferences

QuickRead uses Chrome's local extension storage to remember reading speed,
punctuation pauses, jump distance, playback shortcuts, and the panel's position.
It does not use Chrome's synchronized storage. These settings are used only to
provide the reader's features. Panel size and display mode last only until the
reader closes.

You can change preferences in QuickRead's settings. Removing the extension
removes its saved local extension data.

## Permissions

- **activeTab:** temporarily access the current webpage when you invoke QuickRead.
- **scripting:** inject the reader and access your selection on that page.
- **storage:** save the preferences and panel position described above.

QuickRead does not request persistent access to all websites.

## Sharing and limited use

QuickRead has no analytics, advertising, accounts, or text-upload service. It does
not collect browsing history or transmit selected text or preferences. The developer
does not receive or sell this data, and it is not used for advertising or profiling.
All extension code is included in the installed package.

QuickRead's use of information received through Chrome APIs adheres to the Chrome
Web Store User Data Policy, including its Limited Use requirements. Information
is used only to provide the extension's reading features.

## Questions and changes

For privacy questions, [open an issue](https://github.com/TanishAgrawal/QuickRead/issues)
without including private webpage text or other sensitive information. If you
choose to contact the maintainer through GitHub, GitHub handles that communication
under its own privacy policy.

Future changes to this policy will be posted here with an updated effective date.
